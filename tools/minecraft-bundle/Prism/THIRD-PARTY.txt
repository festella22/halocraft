HaloCraft ships this copy of Minecraft's launcher setup so HaloCraft.exe can start Minecraft by itself.
HaloCraft doesn't include Minecraft: Prism Launcher downloads it after you sign in with a
Microsoft account that owns Minecraft: Java Edition.
